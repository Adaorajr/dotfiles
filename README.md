# Dotfiles

Personal configuration files managed with GNU Stow.

## Contents

- `nvim/.config/nvim/` — Neovim configuration and plugin lockfile.
- `tmux/.tmux.conf` — tmux settings, Vim-style copy mode, and clipboard integration for macOS.

The package layout mirrors paths under `$HOME`, so each package can be linked with Stow after backing up any existing target files.
